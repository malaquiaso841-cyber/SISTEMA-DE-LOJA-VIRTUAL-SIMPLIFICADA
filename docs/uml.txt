Diagrama UML do Sistema de Loja Virtual Simplificada

Diagrama em Mermaid. Visualizadores Markdown compatíveis podem renderizar o bloco abaixo.

~~~mermaid
classDiagram
    class Produto {
        +String sku
        +String nome
        +float preco
        +int estoque
        +String categoria
        +bool digital
    }
    class Cliente {
        +String nome
        +String email
        +Endereco endereco
    }
    class Endereco {
        +String rua
        +String cidade
        +String uf
        +String cep
    }
    class Carrinho {
        +Cliente cliente
        +adicionar_produto(produto, quantidade)
        +remover_produto(sku)
        +calcular_total()
    }
    class ItemCarrinho {
        +Produto produto
        +int quantidade
        +float preco_unitario
        +subtotal
    }
    class Cupom {
        +String codigo
        +float desconto
        +datetime validade
        +validar()
    }
    class Frete {
        +calcular(endereco, itens)
    }
    class ItemPedido {
        +String sku
        +int quantidade
        +float preco_unitario
        +bool digital
        +String categoria
        +subtotal
        +to_dict()
        +from_dict(dados)
    }
    class Pagamento {
        +String metodo
        +float valor
        +processar()
    }
    class Pedido {
        +String id
        +datetime data_criacao
        +String status
        +List~ItemPedido~ itens
        +fechar_pedido_com_carrinho(carrinho)
        +registrar_pagamento(pagamento, produtos)
        +cancelar_pedido(janela_horas, produtos)
        +calcular_total_pedido()
    }
    class Cadastros {
        +criar_produto()
        +criar_cliente()
        +criar_cupom()
    }
    class OperacoesPedido {
        +criar_pedido()
        +cancelar_pedido()
        +registrar_pagamento()
    }
    class Relatorios {
        +gerar_relatorio_vendas_por_periodo()
        +gerar_relatorio_vendas_por_categoria()
        +gerar_relatorio_vendas_por_uf()
        +gerar_relatorio_pedidos_por_status()
        +gerar_relatorio_top_produtos_e_ticket_medio()
        +gerar_relatorio_estoque()
    }
    class Configuracao {
        +carregar_configuracoes()
    }
    class PersistenciaJSON {
        +carregar_produtos()
        +salvar_produtos()
        +carregar_pedidos()
        +salvar_pedidos()
    }
    class LojaGUI
    class MenuCLI

    Cliente *-- Endereco
    Carrinho o-- ItemCarrinho
    ItemCarrinho --> Produto
    Carrinho --> Cliente
    Pedido *-- ItemPedido
    Pedido --> Cliente
    Pedido --> Cupom
    Pedido --> Pagamento
    Pedido ..> Frete
    Cadastros ..> Produto
    Cadastros ..> Cliente
    Cadastros ..> Cupom
    OperacoesPedido ..> Pedido
    OperacoesPedido ..> PersistenciaJSON
    Relatorios ..> PersistenciaJSON
    LojaGUI ..> Cadastros
    LojaGUI ..> OperacoesPedido
    LojaGUI ..> Relatorios
    MenuCLI ..> Cadastros
    MenuCLI ..> OperacoesPedido
    MenuCLI ..> Relatorios
~~~

Observação: o produto é representado por uma única classe `Produto`, que possui o atributo booleano `digital`; o projeto não define subclasses separadas para produtos físicos e digitais.

Os nomes dos métodos de serviço no diagrama representam as responsabilidades do sistema. Consulte os arquivos em `models/` e `services/` para a implementação detalhada.
